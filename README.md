### 1. Saarthi Nexus — AI-Powered Placement Intelligence Platform

<p>
  <a href="https://github.com/Abhi150405/SAARTHI_NEXUS">
    <img src="https://img.shields.io/badge/GitHub-Repository-black?style=for-the-badge&logo=github" />
  </a>
  <img src="https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white" />
  <img src="https://img.shields.io/badge/FastAPI-009688?style=for-the-badge&logo=fastapi&logoColor=white" />
  <img src="https://img.shields.io/badge/MongoDB%20Atlas-47A248?style=for-the-badge&logo=mongodb&logoColor=white" />
  <img src="https://img.shields.io/badge/Google%20Gemini-8E75B2?style=for-the-badge&logo=googlegemini&logoColor=white" />
</p>

An AI-powered placement intelligence platform designed to help students prepare for campus recruitment through centralized placement information and intelligent assistance.

**Key Features**
- 📚 Centralized information about companies, placement requirements, and interview experiences.
- 🎯 Skill-gap analysis to help students identify areas for improvement.
- 🤖 Multimodal RAG chatbot for retrieving relevant placement information.
- 🔎 Semantic search to retrieve relevant information from the knowledge base.
- 📊 Organized placement resources to support interview preparation.

**Technical Highlights**
- Developed backend APIs using FastAPI.
- Integrated Google Gemini embeddings for semantic representation.
- Used MongoDB Atlas Vector Search for storing and retrieving embeddings.
- Implemented cosine similarity-based retrieval.
- Migrated from an in-memory vector database to MongoDB Atlas to address memory constraints during deployment.

**Tech Stack:** Python, FastAPI, MongoDB Atlas, Google Gemini Embeddings, RAG
